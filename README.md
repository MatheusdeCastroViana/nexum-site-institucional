# Nexum - Página Institucional

Landing page institucional da Nexum, construída em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` - estrutura e conteúdo da página.
- `styles.css` - identidade visual, layout, responsividade e animações.
- `script.js` - Scroll Reveal, menu mobile, header e contador do hero.

## Como abrir no VS Code

1. Extraia/abra esta pasta no VS Code.
2. Abra `index.html`.
3. Se tiver a extensão **Live Server**, clique com o botão direito no `index.html` → **Open with Live Server**.
4. Caso não tenha, você pode abrir o arquivo diretamente no navegador.

## Antes de publicar

### 1. WhatsApp do Gustavo

No `index.html`, procure:

`https://wa.me/5500000000000`

e substitua pelo número real no formato internacional, sem espaços ou símbolos.

Exemplo de estrutura:

`55 + DDD + número`

### 2. Domínio

Depois de registrar o domínio da Nexum, configure o deploy e o domínio no serviço de hospedagem escolhido.

### 3. Copy

A página foi montada usando a copy fornecida pelo Gustavo como conteúdo-base. O texto não deve ser alterado sem uma decisão de posicionamento.

## Identidade visual

Direção escolhida:

- Fundo: grafite/navy quase preto.
- Texto: branco e cinza frio.
- Acento: azul elétrico/ciano.
- Apoio: violeta discreto.
- Tipografia: Manrope + DM Sans.
- Linguagem visual: B2B premium, tecnologia, precisão, dados e escala.

## Próxima evolução

Quando a validação comercial gerar os primeiros padrões de dor, a página pode evoluir de uma institucional ampla para uma página orientada ao segmento/problema validado.
